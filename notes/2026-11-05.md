## Confused

I confused about clauses like where should I put them, before or after.

This is the answer you were looking for. Write order:

==SELECT → FROM → JOIN ... ON → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT==

The database actually runs them in this order:

==FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT==

```WHERE``` ==filters individual rows before grouping==, so it can’t use AVG() or COUNT().
```HAVING``` ==filters groups after aggregation==, so it’s where AVG(rating) >= 4 goes.
