## Confused

A question in the assessment, where was the NAT gateway launched when creating the VPC using the wizard?

- In the private subnet (NAT gateways must be launched in a public subnet to function correctly. The lab diagram shows the NAT gateway is launched in the public subnet, allowing private subnet resources to access the internet.)
